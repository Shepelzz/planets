# Путешествие к планетам

3D-планетарий для детей: Солнце, восемь планет и Луна среди звёзд. Можно подлететь к любой
планете, покрутить её и почитать рассказ с фактами. Интерфейс и озвучка на украинском
(записанный голос Кіра из ElevenLabs); сделан под компьютер и iPad.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5210, доступно и из локальной сети
npm run build    # статическая сборка в dist/
npm run check    # типы + сборка + проверка синтаксиса для Safari 12 (перед коммитом)
```

## Озвучка

**Все тексты — в одном файле `texts.yaml`** (единственный источник: названия, значения на карточках,
что говорит голос, слои разреза, факты, строки интерфейса и index.html). Комментарии — строкой с `#`.
Код берёт их через `src/content.ts` (приложение) и `scripts/content.ts` (скрипты озвучки);
`src/texts.ts` проверяет файл и при ошибке называет тело и поле.

Всё, что приложение произносит, заранее записано в `public/voice/` (AAC, имя файла — хеш текста):
на старых iPad (iOS 12) украинского голоса нет, и браузер читал бы текст русским.

**Голос — Кіра из ElevenLabs, модель Eleven v4** (`scripts/elevenlabs-config.json`, без своих
настроек интонации — у v4 лучше всего звучат её собственные). В `.env.local` (он в `.gitignore`) —
только ключ `ELEVENLABS_API_KEY`. После любых правок `texts.yaml` (только macOS):

```bash
npm run voice:all
```

Это два шага: `npm run voice` пишет недостающие фразы бесплатной Lesya (черновик, обновляет список
`src/voice-manifest.json` и удаляет записи исчезнувших фраз), затем `npm run voice:el` перезаписывает
всё новое и изменённое голосом Кіра. Журнал `scripts/elevenlabs-progress.json` помнит, что уже
записано Кірой; если кончится лимит, скрипт остановится и при следующем запуске продолжит с того же
места. `npm run voice:el -- --status` показывает, что осталось (ничего не тратит), `--samples id1,id2`
пишет пробу голосов в `voice-samples/`. Фразы без записи приложение прочитает синтезатором браузера.

Кэш: записи, карты (`public/textures`) и модели (`public/models`) отдаются с Render как неизменные
на год. Для карт и моделей Vite при сборке считает отпечатки файлов (`assetVersions` в
`vite.config.ts`), приложение просит `textures/mars.jpg?v=<отпечаток>` (`src/assets.ts`): заменённая
карта сразу приходит по новому адресу. Для озвучки так же: а в `src/voice-manifest.json` у каждой — отпечаток
файла; приложение просит `voice/<ключ>.m4a?v=<отпечаток>`. Перезаписанная фраза (новый голос, новый
дубль) получает новый адрес, и браузеры скачивают её заново; остальное берётся из кэша. Оба скрипта
озвучки обновляют список сами. В памяти приложение держит фразы открытой карточки и вступления
планет (`preload` в `src/speech.ts`), чтобы голос начинался сразу по нажатию.

## Деплой на Render

В репозитории есть `render.yaml` (Static Site): сборка `npm ci && npm run build`, публикуется `dist/`.
В Render: **New → Blueprint** и выбрать этот репозиторий, или **New → Static Site** с теми же
командой сборки и папкой публикации.

### Адреса и превью ссылок

У каждого вида свой адрес: `/solar-system` — вся система (корень `/` сам переходит туда), `/earth`,
`/moon`, `/iss`, `/europa`… — отдельное тело (id из `src/data.ts`). Ссылка открывает приложение
сразу на этом теле; «назад/вперёд» переключают посещённые. При сборке для каждого адреса делается
своя страница `dist/<id>.html` со своими заголовком, описанием (вступление тела) и картинкой-превью
(`pages()` в `vite.config.ts`), а `render.yaml` направляет `/<id>` на неё — сборка остановится, если
для какого-то тела нет правила (новое тело → добавить два rewrite: `/<id>` и `/<id>/`).

Картинки превью — `public/og/<id>.jpg` (1200×630, настоящий кадр из приложения с подписью). Чтобы
переснять (например, после добавления тела): `npm run dev`, открыть сайт и в консоли браузера
выполнить `space.makeOgCards()` (или `space.makeOgCards(['saturn'])`); вкладка должна быть видна.
Обзор системы использует `public/og.jpg`.

Для поисковиков там же: в каждой странице `<link rel="canonical">` и скрытый для глаз текст с
содержимым карточки (вступление, цифры, факты; у обзора — ссылки на все тела), плюс
`robots.txt` и `sitemap.xml` со всеми адресами (sitemap — только когда известен адрес сайта:
`RENDER_EXTERNAL_URL` на Render или `SITE_URL`).

## На экран «Домой» и офлайн

Иконка — Сатурн (`public/icons/`), манифест `manifest.webmanifest` собирается из `texts.yaml`
(название и описание). Переснять иконку: `npm run dev`, в консоли `space.makeIcon()` (или
`space.makeIcon('earth')`) → `public/icons/source.png`, из него нарезать 180/192/512 и maskable 512.

Собранный сайт работает без интернета (`dist/sw.js`, `offline()` в `vite.config.ts`): приложение и
стартовые карты сохраняются при первом визите, озвучка, 4K-карты и модель МКС — по мере
использования. Старые версии файлов удаляются при обновлении. Проверить: `npm run build && npm run
preview`, открыть, остановить сервер и перезагрузить страницу.

## Старые iPad (iOS 12)

Сборка нацелена на Safari 12 (`build.target` в `vite.config.ts`), поэтому Three.js закреплён на
r162 — последней версии с WebGL 1. Все устройства стартуют с 2K-копий тяжёлых карт
(`public/textures/lite/`); 4K-карта подгружается только для тела, к которому подлетели, и выгружается,
когда улетаем (`showDetail` в `src/bodies.ts`) — иначе 4K всех тел занимали ~400 МБ видеопамяти.
Млечный Путь в 4K только на компьютерах. На WebGL 1 4K не грузится вовсе, и плотность пикселей
ограничена. Pointer Events для Safari < 13 даёт
полифил `pepjs`. Проверить этот режим на обычном браузере: открыть `/?webgl1`.

## Устройство

- `src/main.ts` — сборка сцены и связка частей, цикл кадров.
- `src/camera.ts` — фокус, перелёты, «езда» вместе с телом, кадрирование под панели, пределы зума.
- `src/systems.ts` — спутники, видимые только при визите, и раздвижка орбит.
- `src/routes.ts` — адреса (`/solar-system`, `/earth`…), история «назад/вперёд».
- `src/labels.ts` — подписи над телами и выбор тела касанием.
- `src/devTools.ts` — съёмка превью и иконки (только `npm run dev`).
- `src/bodies.ts` — шейдеры планет, атмосфер, облаков, колец и Солнца.
- `texts.yaml` — все тексты (см. «Озвучка»).
- `src/data.ts` — размеры, орбиты, текстуры каждого тела (без текстов).
- `src/structure.ts` + `src/cutaway.ts` — «З чого складається»: слои (границы, цвета) и разрез как в учебнике
  (вырезанная долька, послойный рассказ с подсветкой слоя).
- `src/phrases.ts` — полный список фраз для озвучки (его используют оба скрипта записи).
- `src/ui.ts`, `src/style.css` — панели и нижняя полоса планет.
- `src/station.ts` — МКС издалека: модель из простых фигур (без файлов), крылья-батареи поворачиваются
  к Солнцу, в тени Земли станция темнеет. Она же иконка и запасной вариант.
- Спутники планет-гигантов и Марса видны только когда летишь к их планете (`moonsWhenNear` в data.ts).
  Пока гостишь у планеты, орбиты расступаются (`src/systems.ts`): внутренние на месте, планета — втрое
  дальше от внутреннего соседа, все внешние — впятеро дальше от неё; орбиты чужих систем гаснут.
  В обзоре всё возвращается.
- Комета (`comet` в data.ts, `makeComet` в bodies.ts): вытянутая петля вокруг Солнца за ~5 минут,
  ядро-«картофелина» с придуманной поверхностью, светящаяся голова и два хвоста (голубой газовый и
  изогнутый пылевой), всегда от Солнца; у Солнца растут, вдали почти гаснут. Камера летит в её
  системе координат, чтобы хвосты были сбоку. Свои блоки карточки, без разреза и сравнения с Землёй.
- `src/stationModel.ts` — МКС вблизи: настоящая модель NASA (`public/models/iss.glb`, для старых iPad
  `iss-lite.glb`), грузится только при подлёте; крылья тоже поворачиваются к Солнцу. Модель ужата
  скриптом `scripts/iss-model.mjs` (как перезапустить — в шапке скрипта). У станции (`station: true` в data.ts) свои блоки карточки — любые ключи
  в `stats` texts.yaml, без разреза и без сравнения с Землёй; камера летит вместе с ней, Земля всегда внизу.
- Чёрная дыра Стрілець A* (`sagittarius`, вид как Гаргантюа из «Интерстеллара»): свой «мир» `galaxy`
  (`realm` в data.ts) — видна только текущая система, переход гиперпрыжком (`src/warp.ts`: картинка
  размывается к центру, звёзды текут лучами, вспышка, прибытие). В нижней панели — справа после
  кометы, у дыры — она и Земля для возврата. Рисуется не сценой, а трассировкой света на каждый
  пиксель (`src/blackhole/shader.ts`, `view.ts`); качество по устройству (старые iPad — меньше
  пикселей и шагов, без свечения) и само снижается, если кадры медленные. Прототип отдельно:
  `/blackhole.html`.
- Отладка из консоли: `space.flyTo('saturn')`.

## Текстуры

Карты планет и панорама Млечного Пути — [Solar System Scope](https://www.solarsystemscope.com/textures/),
лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), на основе данных NASA.
Уменьшены до 4K/2K.

Карты Плутона и Харона — глобальные мозаики NASA / New Horizons (Плутон — Wikimedia Commons,
Харон — USGS Astrogeology), общественное достояние. Юг обоих не снимали (полярная ночь во время
пролёта): шейдер заполняет его отражённой северной поверхностью; серую карту Харона он же тонирует
и добавляет рыжую полярную шапку.

Карты спутников (Іо, Європа, Ганімед, Каллісто, Титан, Енцелад, Тритон, Фобос, Деймос) — NASA 3D
Resources, общественное достояние, ужаты до 1024×512. Серые карты шейдер раскрашивает, а пропуски
(неснятые места у Каллісто и Тритона, полюса Іо) заполняет (`src/surfaces.ts`).

Модель МКС — NASA 3D Resources, «International Space Station (ISS) (D) (IGOAL)», общественное
достояние; ужата с 96 МБ до ~3 МБ (лёгкая версия ~2 МБ).

Облака Земли вблизи «оживают»: шейдер медленно сдвигает и меняет их карту и рисует их тени на
поверхности (только на устройствах с WebGL 2, издалека выключено).
