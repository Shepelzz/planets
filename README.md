# Путешествие к планетам

3D-планетарий для детей: Солнце, восемь планет и Луна среди звёзд. Можно подлететь к любой
планете, покрутить её и почитать рассказ с фактами. Интерфейс и озвучка на украинском
(голос Lesya встроен в устройства Apple); сделан под компьютер и iPad.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5210, доступно и из локальной сети
npm run build    # статическая сборка в dist/
```

## Озвучка

Всё, что приложение произносит, заранее записано голосом Lesya (uk-UA) в `public/voice/`:
на старых iPad (iOS 12) украинского голоса нет, и браузер читал бы текст русским. После
изменения текстов в `src/data.ts` или `src/narration.ts` нужно перезаписать (только macOS):

```bash
npm run voice
```

Фразы без записи приложение прочитает встроенным синтезатором браузера.

Основной голос — Lily из ElevenLabs (модель `eleven_multilingual_v2`): `npm run voice:el`. Голос,
модель и настройки интонации зафиксированы в `scripts/elevenlabs-config.json`, в `.env.local`
(он в `.gitignore`) — только ключ `ELEVENLABS_API_KEY`. Бесплатной квоты не хватает на все фразы сразу, поэтому скрипт
пишет по приоритету и ведёт журнал `scripts/elevenlabs-progress.json`; когда квота кончается, он
останавливается, а повторный запуск (в следующем месяце или с другим ключом) продолжает с того же
места. `npm run voice:el -- --status` показывает, что осталось; то же — в поле `pending` журнала. Незаписанные фразы звучат Lesya.

## Деплой на Render

В репозитории есть `render.yaml` (Static Site): сборка `npm ci && npm run build`, публикуется `dist/`.
В Render: **New → Blueprint** и выбрать этот репозиторий, или **New → Static Site** с теми же
командой сборки и папкой публикации.

## Старые iPad (iOS 12)

Сборка нацелена на Safari 12 (`build.target` в `vite.config.ts`), поэтому Three.js закреплён на
r162 — последней версии с WebGL 1. На WebGL 1 приложение само берёт 2K-карты из
`public/textures/lite/` и ограничивает плотность пикселей. Pointer Events для Safari < 13 даёт
полифил `pepjs`. Проверить этот режим на обычном браузере: открыть `/?webgl1`.

## Устройство

- `src/main.ts` — сцена, камера, перелёты между планетами, выбор касанием.
- `src/bodies.ts` — шейдеры планет, атмосфер, облаков, колец и Солнца.
- `src/data.ts` — размеры, орбиты и факты о каждом теле.
- `src/narration.ts` — что голос рассказывает при нажатии на блоки карточки (для пятилетнего ребёнка).
- `src/structure.ts` + `src/cutaway.ts` — «З чого складається»: слои каждого тела и разрез как в учебнике
  (вырезанная долька, послойный рассказ с подсветкой слоя).
- `src/phrases.ts` — полный список фраз для озвучки (его используют оба скрипта записи).
- `src/ui.ts`, `src/style.css` — панели и нижняя полоса планет.
- Отладка из консоли: `space.flyTo('saturn')`.
