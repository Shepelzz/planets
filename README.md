# Путешествие к планетам

3D-планетарий для детей: Солнце, восемь планет и Луна среди звёзд. Можно подлететь к любой
планете, покрутить её и почитать рассказ с фактами. Интерфейс сделан под компьютер и iPad.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5210, доступно и из локальной сети
npm run build    # статическая сборка в dist/
```

## Деплой на Render

В репозитории есть `render.yaml` (Static Site): сборка `npm ci && npm run build`, публикуется `dist/`.
В Render: **New → Blueprint** и выбрать этот репозиторий, или **New → Static Site** с теми же
командой сборки и папкой публикации.

## Устройство

- `src/main.ts` — сцена, камера, перелёты между планетами, выбор касанием.
- `src/bodies.ts` — шейдеры планет, атмосфер, облаков, колец и Солнца.
- `src/data.ts` — размеры, орбиты и факты о каждом теле.
- `src/ui.ts`, `src/style.css` — панели и нижняя полоса планет.
- Отладка из консоли: `space.flyTo('saturn')`.
